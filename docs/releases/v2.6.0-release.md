# v2.6.0-release

2026-11-09，记录自 `2.5.0-release` 以来的 Lightning SLAM、地图 HTTP 接口和部署更新。本版本以 `dev-humble` 当前提交为发布基线。

## Lightning SLAM 与地图

- 将 Lightning-LM 纳入常规构建和 Docker 源码重部署流程，补充地图路径容错及建图、定位排查记录。
- 改进 Lightning 回环候选校验：子图去地面并增加 ICP 二次校验，同时修复 ICP 校验中的 Eigen 矩阵块索引错误。
- 修正回环 ICP 位姿组合顺序。ICP 输入点云已先由初始变换 `Tw2` 放到目标坐标系，最终位姿需计算为 `T_icp * Tw2`；此前错误的 `Tw2 * T_icp` 可能生成不正确的回环约束，影响优化后的轨迹和地图。
- 地图需由包含上述修正的 Lightning 程序重新构建；既有地图不会被代码更新自动修复。
- 增加实时二维地图 HTTP 获取能力，并完善地图上传、下载及 3D 地图导出相关接口。

## HTTP 服务与部署

- 将机器人 HTTP 能力统一到一个监听端口，由统一服务按 URL 路由分发给各 handler，涵盖地图、URDF/资源等服务；上位机接口协议保持不变，调整服务地址即可切换。
- 增加 Docker 容器内源码更新后的重部署命令，完善 Lightning 源码构建和运行时部署流程。
- 补充统一 HTTP 接口、地图路由验证和 Lightning 建图/定位的运维文档。

## 验证范围与已知边界

- 本次提交包含 ICP 变换组合顺序修正。该工作区未执行构建或自动化测试；发布后应重新编译 Lightning，并使用修正后的程序重新建图，再复测导航表现。
- 本 tag 汇总记录 2.5.0 之后的功能更新，不代表所有地图、场景和部署组合均完成回归验证。
- Lightning 回环效果依赖候选检测及点云匹配质量；回环相关改动不等同于对任意场景定位精度的保证。
