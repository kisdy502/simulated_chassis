# v2.2.0-stable

2026-11-02，算法优化前的功能基线。此 tag 包含自 `v2.1.0-release` 以来的功能提交，以及本次导航分层重构；“stable”表示当前开发基线，不代表所有实机与长时间运行场景已验证。

## 本阶段新增功能

- 支持 Lightning-LM 与 Cartographer 建图、定位后端选择，补充 Lightning 配置、源码适配与排查文档。
- 支持底盘与 UR5e、双臂组合仿真，增加机械臂动作适配、夹爪控制及相关进程生命周期管理。
- 提供 3D 地图、URDF、mesh 获取接口与共享资源服务；补充相机按需拍照、元数据与上位机展示接口说明。传感器图像流与按需保存照片属于不同能力。
- 新增 C++ 电量模拟节点、充电控制与状态上报。默认充电每分钟增加 1 个百分点，静置每 5 分钟减少 1 个百分点，移动每 2 分钟减少 1 个百分点，按仿真时间积分；支持 SOC 保存恢复及真机 BMS 后端适配边界。
- 新增切图、重定位操作 ID、阶段与终态通知，以及结果查询接口；上位机可区分请求受理和操作完成。
- 增加 FREE 自由绕障导航，明确直线、曲线、自由导航参数约束与失败原因；曲线参数错误不再退化为直线。
- 增加旋转超时、无进展检测、忙碌任务与阶段说明，以及底层动作停止确认和导航恢复保护。
- 纳入 TF2 旧时间戳问题的修复与依赖升级方案、Docker 打包部署调整；专题接口文档统一到根目录 `docs/`。

## 本次提交：导航分层重构

- 将直线、贝塞尔曲线、后退路径生成拆为独立 builder。
- 将 FREE 导航与路径跟随拆为 `FreeNavigationExecutor`、`PathNavigationExecutor`，由 `NavigationManager` 统一持有业务任务、阶段和上层回调。
- 引入 `NavigationExecutionContext`，明确执行器与管理器的调用边界。
- 引入 `Nav2ActionSession`，统一底层动作客户端、代次、反馈事件、取消与超时状态。传输回调只入队，由管理器轮询后处理业务回调，避免客户端与管理器锁顺序形成死锁。
- 保留取消确认与停止确认的区别；迟到的目标受理进行定向取消，旧代次结果不能结束新任务，无法确认停止时保留安全准入限制。
- 补充缺失位姿、重复任务及未知终态的失败处理，并更新源码导读和导航重构文档。
- 同步复合机器人 README 启动示例地图为 `map1027S`。

## 验证记录

- `agv_bridge_v2` 定向构建通过。
- 2026-11-02 再次运行下列 CTest，5 项全部通过：`test_navigation_admission`、`test_navigation_executors`、`test_path_builders`、`test_navigation_readiness`、`test_action_session_lock_order`。
- 覆盖路径生成、FREE/直线/曲线/后退流程、取消、延迟受理、旧结果隔离、未知终态与锁顺序回归；使用隔离 ROS domain，不向运行中的机器人发送移动指令。

## 已知边界与下一阶段

- 本次重构保留既有路径采样、曲线方向规则和控制算法，路线贴合度、到点精度、避障效果仍需单独评估与调优。
- Lightning 不提供完整的全局重定位能力，启动仍需合理初始位姿。
- 切图/重定位成功表示定位检查通过，不等同于几何精度保证或 Nav2 已就绪；操作历史为进程内最近 128 条，bridge 重启后不保留。
- `slam_alive` 是地图消息新鲜度提示，静态定位地图不持续发布时可为 false；不能单独用它判断机器人无定位。
- 仿真充电需要显式充电控制，驶到充电点本身不代表已经连接充电。
- 动作会话关闭不替代底层停止确认；进程生命周期管理仍由所属管理层负责。
